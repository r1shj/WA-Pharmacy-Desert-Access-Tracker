Active shortages (–)

Tier 2 shortages (231 of 234) have open-ended, unconfirmed end dates. These show as "active since [date]," not a confirmed start-to-finish duration — openFDA has no field that reliably marks when most shortages actually resolve, only when FDA first posted the notice. Only 3 shortages in the entire dataset have a confirmed resolution date. Data does not exist before 2012 in this dataset — the slider is bounded to that range.
This map does not know what's in stock at any specific pharmacy. Shortages are reported nationally by the FDA, with no pharmacy-level or Washington-specific location data anywhere in the source. That's why shortages appear only as a list here, never as points on the map — plotting them geographically would imply a precision this data cannot support.
