This is a growth-only history, not a closures record. NPPES (the federal registry this is built on) does not publicly expose when a pharmacy deactivates its registration, so a pharmacy that has since closed will still appear present at every date after it first registered. Moving the slider back in time can only add locations, never remove ones that have actually closed.
Dates before ~2008 reflect a registration deadline, not necessarily real openings. Roughly half of today's pharmacies show a first-registration date clustered in a few months of 2006, lining up with the federal NPI system's rollout — many of those pharmacies had already existed for years and were simply registering for the first time because it became mandatory, not opening that week.
